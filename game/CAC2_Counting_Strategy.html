CAC2 Counting Strategy

CAC2 is a balanced, level-2 blackjack count. Every card that leaves the shoe adds its tag value to the running count. Divide the running count by the decks left to get the true count (TC), then use the index charts further down to know when to deviate from basic strategy.

Basic Strategy

Learn this first. With perfect basic strategy the house edge drops to about 0.5%, which is what makes counting worth it.
